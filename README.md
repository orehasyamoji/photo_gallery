# Photo Frame

iPadでJPEGを余白とともに見る、オフライン対応の写真ビューワー。写真は選択したファイルをそのまま読み、縮小・コピー・アプリ内への保存はしません。サーバーへの写真送信もありません。

## 使い方

1. アプリを開くたびに、開始画面で「フォルダを開く」または「ファイルを開く」を選ぶ。
2. フォルダモードでは一つのフォルダに含まれるJPEGをまとめて表示する。ファイルモードでは選択したJPEGを並べ、一覧の「ファイルを追加」から増やせる。
3. 一覧は3列×2行、6枚ずつ。写真は切り抜かずに収める。
4. 写真をタップすると一枚表示。左右スワイプで移動し、写真のタップで機種名と撮影日を表示・非表示にする。写真の左右の余白をタップしても移動できる。下へスワイプすると一覧へ戻る。
5. アプリを終了または再読み込みすると写真の選択は解除される。次回は再びフォルダまたはファイルを選ぶ。

元JPEGのExifに `Make`、`Model`、`DateTimeOriginal` が含まれていれば表示する。含まれない情報は表示しない。写真自体はオリジナルのままで、拡大操作は設けていない。

## iPadへの設置

このフォルダのファイルを同じ場所に置いて **HTTPS** で公開する。GitHub Pagesならリポジトリのルートに中身を置き、Settings → Pages からブランチ公開を選ぶ。公開URLをiPadのSafariで開き、共有メニューから「ホーム画面に追加」を選ぶ。一度ホーム画面のアプリをオンラインで開くと、アプリ本体がオフライン用にキャッシュされる。オフラインで写真を見るには、元JPEGがiPad上の「ファイル」などからアクセスできる状態にしておく。

HTMLを「ファイル」アプリで直接プレビューするだけではService Workerが動作せず、ホーム画面アプリとしてオフラインで使えない。フォルダ選択は **iPadOS 18.4以降** に対応。それより古い版では「ファイルを開く」でJPEGを複数枚選ぶ。

## 構成

- `index.html` 画面
- `style.css` デザイン
- `app.js` JPEG選択、Exif読み取り、ギャラリー操作
- `sw.js` アプリ本体だけをオフラインで使うためのキャッシュ
- `manifest.webmanifest` とアイコン ホーム画面用

外部ライブラリやビルドは不要。PCで確認する場合はこのフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開く。
